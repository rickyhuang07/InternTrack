# InternTrack

InternTrack is a full-stack web application for tracking internship applications in one place. It provides a centralized dashboard where users can record applications, monitor their status, search and filter their application history, and view individual application details.

## Features

* Add internship applications
* Track application status
* Record company, position, location, dates, job links, and notes
* Search applications by company or position
* Filter applications by status
* Sort applications by:

  * Newest
  * Oldest
  * Company A → Z
  * Company Z → A
* View individual application details
* Navigate between the dashboard and applications list
* Edit application navigation and edit-page foundation
